데일리 기출 출제 시스템 v1

1. index.html을 더블클릭하면 브라우저에서 바로 실행됩니다.
2. 문제은행 > + 문제 등록에서 실제 기출문제 원문과 해설을 등록합니다.
3. 과목 선택 > 출제 조건에서 등록된 문제만 출제합니다.
4. 최근 7/14/30일 출제 문제를 제외할 수 있습니다.
5. 문제지 인쇄/PDF, Word용 파일 출력을 지원합니다.
6. JSON 백업/가져오기로 문제은행을 이동할 수 있습니다.

중요: v1은 브라우저 localStorage에 저장되므로 한 PC/브라우저 기준입니다.
여러 직원이 동시에 쓰려면 다음 버전에서 서버 DB와 로그인 기능을 연결해야 합니다.
PDF 문제/해설 자동등록도 서버/API 단계에서 추가하는 것이 안전합니다.
